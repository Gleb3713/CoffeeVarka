# кофеварька — GitHub Pages

Статическая версия сайта, подготовленная для публикации непосредственно из корня GitHub-репозитория.

## Структура

```text
coffee-site/
├── index.html
├── style.css
├── script.js
├── privacy.html
├── assets/
│   ├── hero.webp
│   ├── interior.webp
│   └── ...
├── src/
│   ├── api/
│   ├── cart/
│   ├── data/
│   ├── security/
│   └── utils/
├── favicon.svg
├── manifest.webmanifest
├── robots.txt
├── .nojekyll
└── README.md
```

**Важно:** `index.html` находится в корне репозитория. Папки `website/` или `dist/` как дополнительный уровень для запуска не нужны.

## Публикация через GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите **содержимое этой папки**, а не саму папку-вложение. В корне GitHub должны находиться `index.html`, `style.css`, `script.js`, `assets/` и остальные файлы.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, нужную ветку (обычно `main`) и папку **`/(root)`**.
5. Сохраните настройки и откройте выданный GitHub Pages адрес.

Все пути сайта сделаны относительными, поэтому проект корректно работает не только на домене верхнего уровня, но и внутри URL вида `https://USERNAME.github.io/REPOSITORY/`.

## Перед публичным запуском

В исходном дизайне остаются демонстрационные контактные данные (`placeholder address`, телефон, email), а также примерный адрес для Google Maps. Их нужно заменить на реальные данные кофейни.

Также замените или удалите демонстрационный canonical/OG URL и данные JSON-LD, если у проекта появится собственный домен.

## Локальная проверка

Можно открыть `index.html` через любой статический HTTP-сервер. Простого `python -m http.server` достаточно; запуск через `file://` для ES-модулей браузера не рекомендуется.
